
# React + GlideLite

This project provides an example how to use GlideLite and all its features with a [React](https://react.dev/) + [Vite](https://vite.dev/) frontend.

All the code in this example is the outcome of following the [documentation](https://github.com/sanderveldhuis/glidelite/blob/main/doc/getting-started.md) of GlideLite.

## Recommendation

If you are developing a production application, we recommend using TypeScript. Check out the [TypeScript example](https://github.com/sanderveldhuis/glidelite/tree/main/examples/example-react-ts) for information on how to integrate TypeScript in your project.
